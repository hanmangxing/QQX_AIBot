# QQ星 V1.0.0 安装教程

QQ星V1.0.0安装文档

奶人级保姆级简单详细，预设加群拿：1132194482

网盘链接：https://pan.quark.cn/s/de0af909ec88?pwd=q77j

由于Sl的稳定性已经强Napcat太多，所以，哪怕我的项目兼容Napcat，我也强烈建议部署SL

如果你有Agent的话，可以直接把仓库地址给Agent让他安就行了，如果没有的话，这里提供手动部署教程

首先，你的设备必须有Python环境，如果没有的话，使用奶人网盘包里的python安装文件进行安装，只需要双击安装文件，勾选两个方框，然后一路安装之后，如果有可能弹出的

命令行里面，这边你一直用英文输入法输入Y就行

![图 01](images/教程-01.png)

![图 02](images/教程-02.png)

Python安装完之后解压项目的压缩包，点击一键启动（日后你可以根据自己的需求，右键创建快捷方式）

点击启动之后，会弹出Web UI界面，先不用管它，去解压SL

最终指向你电脑上snowluma的.launcher.bat文件路径即可

![图 03](images/教程-03.png)

解压出来之后，把launcher文件在你电脑上的位置路径复制

![图 04](images/教程-04.png)

![图 05](images/教程-05.png)

然后点击启动，一般来说会跳转到SnowLuma的控制台；如果没有的话，你就点图片上那个蓝色的端口网址

同时，初次登录SnowLuma控制台时使用Token密码

![图 06](images/教程-06.png)

,在控制台上面，蓝色的Password部分

![图 07](images/教程-07.png)

![图 08](images/教程-08.png)

然后设置你自己的访问密码。这边可以把密码保存在浏览器里，以免忘记

然后登录你要用作Bot的QQ

![图 09](images/教程-09.png)

![图 10](images/教程-10.png)

,建议使用小号，具体按你自己需求，但这个小号里加的人和群最好少一点

![图 11](images/教程-11.png)

握手成功就部署OK了，然后配置好API就行，如果没有API key，其实一把硅基流动的APIkey就可以满足本项目的全部API需求

https://cloud.siliconflow.cn/i/UEMDqkh9

LLM API就是主对话模型，推荐Geimini 3.8F，DeepseekV3.2，当然其他的也可以

![图 12](images/教程-12.png)

表情包识图模型只需要有多模态的就行，例如qwen3 8B

秘书网关模型是用于推断是否需要插话的，低成本模型即可，推荐qwen2.5 7B(因为硅基流动免费。)

然后外审拦截功能对于Gemini模型有大用，会把道歉、空回等结果自动识别，并且重roll，这也是如果我做AstrBot的插件以及酒馆套壳，我没有办法做到的部分，

![图 13](images/教程-13.png)

然后第二个页签：预设部分，由于平台规则和社区规则，我不能在这个开源项目里提供这部分预设，如果你想要我用的得到原作者(s一串)授权的稳定可用的版本，加群(1132194482)里自取即可

![图 14](images/教程-14.png)

,同时你如果动手能力强,喜欢的酒馆预设也可以把条目缝到这里，预设的返回工具是什么，就在这个正文工具名里填什么

然后世界书部分酒馆玩家们反正就很熟悉了，但我这个项目其实不是让你在QQ上玩酒馆的，所以没有做的太复杂，都很轻量，你把你喜欢的角色的调色盘，人设词，背景和世界观什么的复制在这里就行了

![图 15](images/教程-15.png)

聊天记录部分，你可以把你和AI的上下文进行隐藏、删除和修改

![图 16](images/教程-16.png)

![图 17](images/教程-17.png)

![图 18](images/教程-18.png)

根据记忆库界面推荐配置，配置4个记忆库专用的API

运行参数中，上下文条数推荐选择“0”；每轮注入推荐20条往上，召回阈值0.25

这个总结阈值按你实际互动的文本量调整，保留最近推荐20条

然后跨会话召回，这看你实际使用场景，我推荐是私聊不开，然后群聊的情况下，只共用群聊的记忆库来

![图 19](images/教程-19.png)

记忆库是对上下文进行的被动记忆与总结，笔记本功能则能让AI自己去主动记忆，主动读取，可以做到让ta更懂你，（也可能更记仇）

![图 20](images/教程-20.png)

我没有nai，所以我目前只接了comfyui的文生图，这里只需要填写本地的comfyui端口地址就行，然后生图的提示词模版也可以自己改，其实这个不需要太大、太复杂的提示词，因为模型其实自己是会写的，只需要简单的规则说明即可

然后表情包功能，可以从聊天中偷取对话中的图片里，表情包收纳进来，这个是真好用

![图 21](images/教程-21.png)

点击魂，就是灵魂系的功能，这里除了郊狼之外的全部功能，我建议全部打开，都是有用的全部配置好了

![图 22](images/教程-22.png)
