        💡 酒馆同款【蓝绿灯】规则机制说明：
      

      

        
🔵 蓝灯 (常驻)：永久置入 Prompt 角色与世界观位置，每一轮均生效。

        
🟢 绿灯 (动态)：当用户发送的消息中包含该条目的标题或任意关键词时才激活注入。

        
⚪ 关灯 (禁用)：完全不注入。

        
🖐 拖动排序：按住条目左侧把手上下拖动，即可调整注入顺序（顺序即实际发给 API 的顺序）。
