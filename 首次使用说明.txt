QQX_AIBot v1.0.0 —— 首次使用三步

1. 装 Python 3.10 或更高版本（python.org 下载，安装时勾上 "Add Python to PATH"）
2. 解压到一个不含中文、不含空格的路径，例如 D:\QQX_AIBot
3. 双击 一键启动.bat —— 它会自动安装依赖、启动服务、并打开控制台（http://127.0.0.1:8090）

然后在控制台「设置 → API 配置」里填你自己的模型接口地址和密钥。

想让它在 QQ 里说话，还需要一个协议端（NapCat 或 SnowLuma），
在控制台「设置 → 协议端」里选，具体步骤见 README.md。

包里没有任何人的密钥和聊天记录。更新不会覆盖你自己的 config.json、聊天记录、记忆和贴图库。

版本号见 version.py，更新内容见 CHANGELOG.md；
检查更新在控制台右上角齿轮 →「版本与更新」。
